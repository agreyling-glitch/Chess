## Added

- Online play through the Free Internet Chess Server (FICS), with guest access and sign-in for existing accounts.
- Available-game listings, unrated seeks with custom time and increment, direct player challenges, and incoming challenge controls.
- Live server-controlled boards and clocks, with finished online games saved locally for later analysis.
- Observation tabs for watching up to 10 FICS games simultaneously. Once a game finishes, run full-game analysis to review its moves and key moments.
- Player and channel chat tabs alongside the FICS console, with unread counts and separate message drafts. Conversations remain available for the current session.
- Random Chess960 starting positions and custom FEN positions for local play.
- A visual position editor with piece placement, board rotation, and editable game-state details.
- Screenshot import through upload, paste, or drag and drop. Recognition runs on the device and produces a position that can be checked and corrected before starting.

- An Observed category in Saved Games for finished watched games, with FICS source labels, automatic analysis-progress saves, and resumable partial analysis.
- An All Games view with shared player and text search, favorites, and Not analyzed, Partial, and Complete analysis filters. Observed games are included in backups.

## Improved

- Switching observation tabs pauses analysis and preserves completed results for the original game.
- Larger, scrollable Available games and Observe a game menus with more room for player names and time controls.
- The FICS console opens automatically on connection. Chat uses the same readable monospace font as the console, and server replies stay in the Console tab.
- Online Controls sits beside Help in the main menu.
- A new Ironwood knight logo across the website, About dialog, app icons, and favicons, with compressed images suited to each placement.
- A redesigned home-page introduction and an expanded features page covering engine play, online play, spectating, chat, and position tools.

## Local and online

Stockfish analysis and screenshot recognition run locally. FICS play, observation, and chat require a connection and exchange game activity and messages with the server. Chat permissions depend on the FICS account and channel. Review recognized pieces and position details before using an imported screenshot.
