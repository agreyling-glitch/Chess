Companion **0.1.8** supersedes 0.1.7. It includes Windows sign-in startup, server-side archive backups and restore, and unified collection filtering, plus a fix for restarting after an update.

- Serialize the restart executable as a plain JSON filename, instead of Windows-specific OS-string data.
- Restrict restart targets to the two Companion package entry points.
- Add regression checks for JSON string serialization and invalid executable rejection. Keep signature verification, checksums, exact-origin checks, healthy-startup checks, and rollback mandatory.

**One manual update is required from 0.1.4 or 0.1.7.** Their existing updater can verify the new package but fails during restart; a new download cannot repair that already-running old helper. Quit Companion, replace the application files in the same folder using the [current Windows ZIP](/downloads/companion/), and preserve the data directory. Version 0.1.8 repairs the handoff for future updates. Do not turn off verification or remove games to work around an update failure.

Previously published 0.1.4 and 0.1.7 ZIPs remain unchanged. Windows x64 remains the only public platform download. See [Companion setup](/help/companion-setup/) and [update troubleshooting](/help/companion-troubleshooting/).
