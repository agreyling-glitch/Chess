## Board and tabbed study workspace

- Replaced the four-panel layout with the live board on the left and **Moves**, **Prediction**, and **Analysis** tabs on the right. Resize the split with the divider.
- Enlarged the Game Moves table text and matched the tab buttons to the main menu’s size and gold-accented appearance.
- Kept Engine Prediction in a compact column within Prediction.
- Moved **Expand** into the evaluation graph’s upper-right corner and **Print analysis** beside the **Saved Analysis** heading. Both use the dark raised toolbar style.
- Replaced the bottom-bar Settings button with an **Engine** button beside the engine name and status.

## Analysis budgets and verification

- Added a full-game **Budget** choice between nodes and **1–60 seconds per position**. Node mode retains Quick, Standard, Deep and Custom quality choices.
- Added **Verify critical moves after analysis** to control the automatic deeper pass. **Verify critical moves** can start that check manually after the first pass, with **Resume verification** for interrupted work.
- Included the engine name on the full-game analysis button.

## Training and imports

- Added **Starting target Elo** when creating a Stockfish training profile, from **1320–3190**. The default remains 1320; both color ratings start at the chosen value.
- Made collection review movable and resizable, with textured sunken sections and raised import controls.
- Added a beveled progress bar for large imports and a result summary for games saved, already saved, failed and not attempted.
- Made Storage Information movable and resizable, with a gold 3D border and scrollable record sections.

## Gallery and Help

- Refreshed Gallery captures for the current workspace, board themes, library and positional insights, and added dedicated Moves and Engine Prediction examples.
- Updated Help for the tabbed layout, current control names and locations, import progress and library controls.
