**Superseded by [Companion 0.1.8](/changelog/2026-10-30-companion-0-1-8/).** The live upgrade test found a restart-path bug shared with 0.1.4; affected installations need one manual update. The 0.1.7 ZIP is retained unchanged.

Companion **0.1.7** was published for Windows 11, Intel/AMD 64-bit, from the [official download page](/downloads/companion/). Use the current download and its manual-update instructions.

- Choose **Start Companion when I sign in** in the native status window to create or remove your Windows Startup shortcut. It preserves your configured data folder.
- Configure a **Backup folder** on the Companion machine. Create database snapshots and restore into an empty archive through **Game History → Backup and Restore…**. Large archives stay on the server; jobs continue if the browser closes.
- Filter and manage collections through **Saved Games** in Browser or a named Companion. Membership changes invalidate cached library counts. Games can belong to several collections without duplicating their stored PGN.
- Select a destination collection when copying or moving games between libraries. Original data is removed only after a successful destination transfer.

The release retains connection tokens, exact website-origin checks, signed update manifests, package checksum verification, and rollback protections. The Windows executable does not have a Windows publisher signature; release-key verification is a separate check. The versioned 0.1.4 ZIP remains unchanged.

Games, engines, tokens, and machine settings stay in the existing data folder. For a manual update, quit Companion before replacing its application files. Back up your archive first. macOS, Linux, and QNAP/NAS remain developer-supported rather than public downloads.
