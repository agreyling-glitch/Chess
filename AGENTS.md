# Ironwood release reminder

When the user asks you to push Ironwood to GitHub, remind them **before pushing** to test the production PWA update flow: install or launch the existing PWA, apply the update, confirm the new app and Saved Games UI load together, then restart it offline and verify a saved game still opens. Ask whether they have completed this check or want to proceed without it. Do not treat a successful local Wrangler refresh as proof that the production PWA update path works.
